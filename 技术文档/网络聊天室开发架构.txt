目标{
开发一个可容纳多人同时聊天对话的网络聊天室，拥有良好的前端功能、用户系统、信息存储系统，具有高稳定性、高负载能力，保证信息准确，处理速度快。
1、前端：可输入显示信息及聊天对话，可对记录进行翻阅。
2、用户系统：存储个人信息，具有好友的功能。
3、信息存储：存储聊天记录等
}

实现技术{
1、数据库：数据库1用于存储用户登录信息+指向用户个人信息的地址，数据库2用于存储用户的个人信息（好友、生日等），数据库三用于存储聊天记录。
2、多线程通信技术：实现多端同时通信的功能，同时利用软件对线程及其数据进行管理。
3、QT：用于聊天室前端搭建
}

具体架构{
架构基础：单服务器+多客户端
单服务器功能：
1、对用户的登录访问进行处理和回复
2、与客户端建立线程进行通信
3、对多线程及其信息进行管理
4、将获取到的信息写入到数据库中/从数据库中读取信息
5、将信息更新到所有客户端
客户端功能：
1、存储部分聊天信息
2、向服务器发送登录请求并根据回复初始化界面
3、向服务器发送信息及收取信息
4、更新聊天室信息
}；

具体实现{
服务器{
1、登录访问部分
2、线程管理部分
3、数据库读取写入部分
}
客户端{
1、登录访问部分
2、聊天室前端界面部分
3、通信访问部分
4、数据存储部分
}

服务器
{
登录访问部分{
1、查询数据库函数（返回个人信息地址）
2、注册添加账号函数（返回个人信息地址）
3、登录通信建立线程监听函数
4、通信线程函数（返回登录以及个人信息）//主程序
 }
线程管理部分{
1、线程创建监听函数
2、通信线程输入函数//主程序
3、定时汇总信息函数（返回汇总后的信息）
4、线程管理函数（用于对线程进行操作）
5、线程信息按时存储函数（用于准确存储用户信息）
6、信息分类处理函数（对从客户端获取的信息进行解析，得知操作命令后进行处理）（返回操作后的信息）
7、定时信息刷新函数（用于向客户端发送更新的信息和待处理的请求）
8、通信线程输出函数//主程序
9、信息分时输出管理函数（返回要输出的信息）
}
数据库读取写入部分{
1、登录信息查询函数（返回登录信息）
2、个人信息查询函数（返回个人信息）
3、历史聊天信息查询函数（返回聊天信息）
4、登录账号录入函数（返回个人信息地址）
5、个人信息录入函数（返回个人信息地址）
6、聊天记录录入函数
7、个人信息创建函数
}
}

客户端{
登录访问部分{ 
1、登录通信线程建立函数
2、操作分类加载成命令函数（返回要输出的命令）
3、输入信息获取函数
}
聊天室前端界面部分{
1、个人信息界面
2、聊天室界面
3、信息初始化函数
}
通信访问部分{
1、通信线程建立函数
2、通信输出线程建立函数
3、通信输入线程建立函数
4、界面信息更新函数
5、操作分类加载成命令函数
6、初始信息初始化比较函数
}
数据存储部分{
1、聊天记录定时存储函数
2、个人信息存储函数
3、聊天记录读取函数
4、个人信息读取函数
}
}
}

服务端与客户端流程图
{
//程序启动初始化
客户端启动程序->客户端.登录通信建立函数->服务端.登录通信建立线程监听函数->服务端.通信线程函数(持续监听)
//登录及进入主界面的初始化
客户端进行操作->客户端.输入信息获取函数->客户端.操作分类加载成命令函数->客户端.登录通信建立函数->服务端.查询数据库函数（登录信息查询函数）\服务端.注册添加账号函数(服务端.登录账号录入函数+个人信息创建函数）->若登录验证通过进入网络聊天室主界面->服务端.通信线程建立函数->服务端.线程创建监听函数->(服务端.通信线程输入函数+服务端.通信线程输出函数)->(客户端.通信输出线程建立函数+客户端.通信输入线程建立函数)->{（（服务端.个人信息查询函数+服务端.历史聊天信息查询函数）->服务端.通信线程输出函数)+（客户端.聊天记录读取函数+客户端.个人信息读取函数）}->客户端.初始信息初始化比较函数->（若匹配相同，用本地数据->客户端.信息初始化函数）/{若匹配不相同，则向服务端申请数据->客户端.通信输出线程建立函数->(服务端.个人信息查询函数+服务端.历史聊天信息查询函数)->服务端.通信线程输出函数->客户端.通信输入线程建立函数->客户端.界面信息更新函数->(客户端.聊天记录定时存储函数+客户端.个人信息存储函数)}
//用户操作发送聊天信息
用户进行操作->服务端.操作分类加载成命令函数->客户端.通信输出线程建立函数->服务端.信息分类处理函数->服务端.线程信息按时存储函数->服务端.定时汇总信息函数->服务端.定时信息刷新函数->服务端.信息分时输出管理函数->{(服务端.通信线程输出函数->客户端.通信输入线程建立函数->客户端.界面信息更新函数->客户端.聊天记录定时存储函数)+(服务端.聊天记录录入函数)}
//用户进行其他操作
用户进行操作->服务端.操作分类加载成命令函数->客户端.通信输出线程建立函数->服务端.信息分类处理函数->服务端.个人信息查询函数+服务端.历史聊天信息查询函数->服务端.通信线程输出函数->客户端.通信输入线程建立函数->客户端.界面信息更新函数->客户端.聊天记录定时存储函数/客户端.个人信息存储函数
//用户退出程序
用户关闭程序->客户端关闭->服务端.线程管理函数->线程被关闭
}


线程分配{
服务端{
1、登录通信建立线程监听函数
2、通信线程函数（登录）//由登录通信建立线程监听函数建立
3、线程创建监听函数（线程管理）
4、通信线程输入函数//由线程创建监听函数建立
5、通信线程输出函数//由线程创建监听函数建立
6、定时信息刷新函数
7、定时汇总信息函数
}
客户端{
1、登录通信线程建立函数
2、通信线程建立函数
3、通信输出线程建立函数//由通信线程建立函数建立
4、通信输入线程建立函数//由通信线程建立函数建立
}
}
